User Roles Overview

Super Admin

Global unrestricted system access across all 5 feature modules.

  • User account management, role assignments, and custom permission grants.
  • Full management of student, teacher, course, examination, and classroom records.
  • System administration, security settings, and audit log tracking.

Teachers

Academic management for assigned students, courses, and classrooms.

  • Manage student academic profiles, attendance tracking, and grade entries.
  • Course enrollment management and classroom availability bookings.
  • Schedule upcoming examinations and input test scores.

Students

Self-service read-only access to academic history and schedules.

  • View personal attendance records and attendance percentages.
  • View fee payment statuses and outstanding payment records.
  • View enrolled courses, exam dates, and published report cards.

Parents

Read-only access strictly scoped to their linked children.

  • View linked child profile information and academic performance.
  • View child attendance percentages and fee payment status.
  • View child upcoming examination schedules and published results.

Feature Modules List

Academy categorizes system functionality into 5 distinct modules. Each module maintains defined responsibilities and access boundaries.

1. Student Module

Central repository for all student-related data and administrative tracking.

  • Profile Details: Personal records, academic history, roll numbers, and contact info.
  • Attendance Tracking: Daily logging, attendance percentage calculation, and history logs.
  • Fee Management: Fee structure definitions, payment statuses, and history logs.
  • Grades & Reports: Grade entries, subject mark updates, and generated report cards.

2. Teacher Module

Handles faculty administration, schedules, and payroll records.

  • Profile Details: Faculty background, subject specializations, and contact details.
  • Class Schedules: Assigned class timetables and teaching allocations.
  • Salary Records: Payroll history, salary structures, and payment disbursements (Administrator access only).

3. Course Module

Manages academic curriculum offerings and student enrollments.

  • Course Definitions: Course codes, titles, syllabi, and assigned faculty instructors.
  • Student Enrollments: Active student registrations per course and enrollment logs.

4. Exam Module

Schedules testing evaluations and stores examination scores.

  • Exam Scheduling: Examination dates, course linkage, and total scoring criteria.
  • Results Entry: Student mark submission, grade calculations, and report card publishing.

5. Classroom Module

Controls physical facility inventory and booking schedules.

  • Classroom Details: Room identifiers, seating capacities, and equipment specifications.
  • Bookings & Availability: Real-time room reservation checking and booking logs.
