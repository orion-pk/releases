User Roles Overview

Super Admin

Global unrestricted system administration and governance.

  • User management, role assignment, and interactive Permissions Matrix control.
  • Full oversight of student records, faculty rosters, lectures, and document archives.
  • System security configuration, audit log tracking, and database exports.

Teachers

Academic and curriculum management for assigned classes and courses.

  • Manage student grades, attendance records, and student feedback notes.
  • Create, schedule, and manage lectures and topic outlines.
  • Upload and verify educational credentials via AI document scanning.

Students

Self-service academic portal for enrolled courses and class schedules.

  • View personalized attendance percentages and fee payment status.
  • Access assigned lecture schedules, syllabi notes, and course materials.
  • View published exam results and term report cards.

Parents

Dedicated monitoring portal scoped exclusively to linked children.

  • Monitor child attendance percentage, daily presence, and class schedules.
  • Track fee status, upcoming billing records, and term report cards.
  • Review scheduled lectures and teacher performance feedback notes.

Platform Feature Modules

Academy organizes system functionality into 6 core modules, each with distinct user workflows and access boundaries.

1. Student Module

Student information tracking, attendance recording, and academic evaluation.

  • Profiles: Student identity, enrollment dates, and parent contacts.
  • Attendance: Daily presence logging and automatic attendance percentages.
  • Grades & Cards: Subject assessment marks and term report cards.

2. Teacher Module

Faculty directory, subject assignments, and teacher feedback notes.

  • Faculty Profiles: Academic qualifications, subject specializations, and CNIC records.
  • Teaching Rosters: Assigned class sections and course allocations.

3. Class & Schedule Module

Classroom scheduling, section rosters, and subject timetables.

  • Class Rosters: Grade levels, section capacities, and student rosters.
  • Timetables: Period allocations and room availability schedules.

4. User Governance & Permissions Module

Administrative account lifecycle and Role Permissions Matrix controls.

  • Account Creation: Registering staff with assigned roles and activation emails.
  • Permissions Matrix: One-click toggling of View, Add, Edit, Delete permissions per role.

5. Lecture & Curriculum Module

Curriculum delivery, topic scheduling, and student roster enrollments.

  • Lecture Scheduling: Setting lecture titles, subject topics, and descriptions.
  • Student Rosters: Enrolling specific students or entire class sections into lectures.

6. Document Verification & OCR Module

AI-assisted document scanning, dual-pane zoom preview, and academic data extraction.

  • Document Uploads: Uploading degrees, Matric/Inter certificates, and CV files.
  • 13-Field Extraction: Automatic capture of student/father name, roll number, total/obtained marks, grade, board, and year.

User Account Activation Workflow

Secure self-service onboarding allows newly registered staff and users to set their own passwords.

1. Administrator Registration

The Super Admin registers a user with an email and role. The account status is initially set to Pending Activation.

2. Secure Activation Link

An invitation email containing a secure, time-limited activation token link is sent directly to the user's inbox.

3. Password Setup

The user opens the activation link, enters their new password, and confirms their personal profile.

4. Automatic Login

Upon activation, the status updates to Registered, and the user is instantly logged into their portal.

AI Document & OCR Intelligence Scanner

Automates the verification of academic degrees and certificates using OCR extraction and live dual-pane inspection.

  • Dual-Pane Interactive Viewer: Inspect high-resolution document scans side-by-side with extracted data, featuring real-time zoom and pan controls.
  • 13 Captured Academic Fields: Automatically extracts Student Name, Father Name, Roll Number, Registration Number, Total Marks, Obtained Marks, Grade, Passing Year, Board/BISE Name, Examination Type, Group/Discipline, Institution Name, and CNIC.
  • In-Place Review & Save: Users can edit any field directly in the review pane before committing data to the permanent profile repository.

Lecture & Curriculum Management

Enables faculty to schedule topics, publish lecture outlines, and manage attending student rosters.

  • For Teachers: Schedule new lectures, define subjects and syllabus topics, and attach participating students.
  • For Students: View upcoming lecture timetables, review lecture outlines, and track assigned courses.
  • For Parents: Monitor scheduled lectures and curriculum progression for linked children.
